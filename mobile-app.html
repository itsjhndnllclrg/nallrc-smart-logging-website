How it works

A 4-step flow from first-time setup to daily library access — offline-capable after the first verification.

1

Download & Verify Once

Student opens the app or web portal and signs in using their university portal credentials. Needs internet only this one time.

2

QR Pass Generated & Saved

The server generates a digitally-signed, encrypted QR token tied to their student ID. It is cached locally on the device — no connection needed to display it later.

3

Arrive, Open App, Scan

At the library kiosk, student opens their pass (works offline), holds it up to the scanner. Kiosk validates the token server-side. Student selects purpose — done in under 30 seconds.

4

Pass Refreshes Periodically

Each semester, the QR token auto-renews when the student next connects to any network — their pass stays current without manual action.

Why offline works here

A QR code is just an encoded string — like the student's ID number wrapped in an encrypted signature. The student's phone only needs to display it. The kiosk scanner is the one that connects to the network to validate. No Wi-Fi required on the student's side at all.
